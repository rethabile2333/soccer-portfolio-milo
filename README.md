## How to Host This Website

### Option 1: Netlify (Easiest - Free)
1. Go to [netlify.com](https://netlify.com) and sign up for free
2. Click "Add new site" → "Deploy manually"
3. Drag and drop this entire folder into the upload area
4. Your site will be live instantly with a free URL like `your-site-name.netlify.app`

### Option 2: GitHub Pages (Free)
1. Create a GitHub account at [github.com](https://github.com)
2. Create a new repository named `milo-classic-tournament`
3. Upload all files (index.html, styles.css, script.js) to the repository
4. Go to Settings → Pages
5. Select "main" branch as source
6. Your site will be live at `your-username.github.io/milo-classic-tournament`

### Option 3: Vercel (Free)
1. Go to [vercel.com](https://vercel.com) and sign up
2. Click "Add New Project"
3. Connect your GitHub repository or upload files
4. Deploy with one click

## Customization

### Adding Your Own Videos
Replace the video placeholders in the HTML with actual YouTube or video embeds:

```html
<div class="video-item">
    <iframe width="100%" height="100%" src="YOUR_YOUTUBE_VIDEO_URL" frameborder="0" allowfullscreen></iframe>
</div>
```

### Adding Your Own Images
Replace the placeholder divs with actual images:

```html
<div class="gallery-item">
    <img src="your-image.jpg" alt="Description">
    <div class="gallery-caption">Your Caption</div>
</div>
```

### Updating Team Information
Edit the teams section in index.html to add your actual participating teams with their real names and locations.

### Updating Contact Information
Update the contact section with your actual email addresses and social media links.
